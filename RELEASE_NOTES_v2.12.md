# AccesShot 2.12 — Windows 11 x64

Primera entrega del proyecto en este repositorio. Versión portátil probada y aprobada por el autor.

- Aplicaciones clásicas y modernas, URL y etiquetas en un lienzo editable.
- Buscador local con filtros para Fotos, Recortes, Enlace móvil y WhatsApp.
- Movimiento, redimensionado y cuatro operaciones persistentes de orden de capas.
- Contornos limpios, temas oscuro/claro y paletas por tipo de objeto.
- Colores predeterminados adaptables al tema y personalización persistente.
- Sobrevuelo configurable y restauración de estilo.
- Confirmación antes de abrir URL y GitHub.
- AccessShot.exe visible al extraer, con runtime incluido en Aplicacion.

Descarga el ZIP de aplicación, extráelo entero y abre AccessShot.exe. Conserva Aplicacion al lado. Las apps detectadas dependen de lo instalado para tu usuario.

Se adjuntan SHA256SUMS.txt y un ZIP complementario de licencias. El ZIP de aplicación es el mismo que validó el autor.
