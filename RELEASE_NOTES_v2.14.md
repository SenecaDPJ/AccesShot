# AccesShot 2.14 — Windows 11 x64

Corrige el error que aparecía al añadir una aplicación instalada de Windows. El selector vuelve a adjuntarse al cuadro de creación de accesos pese al nombre de campo transformado en el núcleo reconstruido.

La disposición de ejemplo de la 2.13 se conserva para perfiles nuevos; las disposiciones guardadas y los datos del usuario permanecen intactos. Se añade una prueba de integración para el selector, además de las comprobaciones del arranque, aviso fuera de pantalla y persistencia.

Extrae el ZIP entero y abre `AccessShot.exe` en la primera carpeta. Conserva `Aplicacion` a su lado. Se adjunta `SHA256SUMS_v2.14.txt`.
