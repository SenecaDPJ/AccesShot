# Consulta histórica

Snapshots recuperados con ILSpy y guiones históricos. No constituyen un pipeline de build completo listo para ejecutar. Los guiones contienen paths del entorno de preparación y deben adaptarse; los snapshots pueden transformar nombres de campos/cierres usados por reflexión.

Los módulos editables están en src. Para la primera release se usa el ZIP validado, no una recompilación de estos snapshots.
