# AccesShot 2.16 — Windows 11 x64

La 2.16 corrige dos regresiones de la 2.15 y actualiza la disposición inicial de la app:

- El aviso de objetos fuera de la vista inicial aparece en la zona superior del lienzo y ya no tapa la firma inferior.
- Se restaura el icono de AccesShot en la barra de título y la barra de tareas.
- En perfiles nuevos, se usa el JSON facilitado por el autor como disposición inicial; no sobrescribe configuraciones existentes.

Se mantienen las funciones de la 2.15. Descarga el ZIP completo, extráelo y abre `AccessShot.exe`. Mantén la carpeta `Aplicacion` junto al ejecutable. El runtime está incluido.

La versión es portable para Windows 11 x64. El repositorio es privado y requiere iniciar sesión en GitHub.
