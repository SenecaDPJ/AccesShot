# Presentación para GitHub

## Descripción del repositorio

Lanzador portátil para Windows 11: organiza aplicaciones clásicas y modernas, enlaces y etiquetas en un lienzo con temas, colores y capas.

## English description

Portable Windows 11 launcher for classic and modern apps, links and labels, with a customizable canvas, themes, colors and layers.

## Frase

Tus aplicaciones, tus enlaces y tus etiquetas, organizados en un lienzo a tu medida.

## Texto breve

AccesShot reúne tus accesos en un lienzo visual y personalizable. Añade aplicaciones de Windows, enlaces web y etiquetas; ordénalos por capas, adapta tamaños y colores y alterna entre tema oscuro y claro. La 2.12 incorpora un buscador de apps modernas instaladas en el equipo.

## Texto promocional

Tu escritorio, a tu manera. AccesShot 2.12 convierte aplicaciones, enlaces y etiquetas en un panel que puedes mover, ordenar y personalizar. Portátil para Windows 11, con apps modernas, capas y temas oscuro/claro.
