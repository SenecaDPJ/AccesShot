# AccesShot 2.15 — Windows 11 x64

AccesShot 2.15 adds canvas rotation, group selection and movement, a clearer bulk-delete confirmation, one-step undo, JSON backups and an Options panel.

- Rotate shapes by 90°; text stays horizontal and readable. New labels can use a vertical layout.
- Drag a rectangle on the canvas to select a group. Ctrl-click adds or removes objects.
- Move a group while preserving relative positions and layers.
- Review names and object counts before deleting. Emptying the entire canvas requires an extra confirmation.
- Ctrl+Z restores the latest saved canvas edit when its recovery snapshot still matches the current configuration.
- Use the small canvas button to create timestamped JSON backups. Options can change the destination or restore a validated copy.
- Ctrl+O opens Options in AccesShot.

## Installation

Download the complete ZIP, extract it, and open `AccessShot.exe`. Keep the `Aplicacion` folder beside the launcher. The runtime is included.

The release is portable and intended for Windows 11 x64. The repository is private, so GitHub access is required.
