# AccesShot 3.0 — Windows 11 x64

## Español

AccesShot 3.0 añade una interfaz en español e inglés para organizar programas, apps modernas de Windows y páginas web en un lienzo personalizable.

- Usa el botón vertical **IDIOMA** entre **MODOS** y **OPCIONES** para alternar entre español e inglés. La bandera muestra el idioma activo.
- La primera ejecución abre en español; la selección se recuerda por usuario en `%APPDATA%\AccessShot\language.json`.
- Los nombres y destinos personalizados de los accesos se conservan al cambiar de idioma.
- Incluye un paquete portable autocontenido para Windows 11 x64. Extrae el ZIP y abre `AccessShot.exe`.

SHA-256 del ZIP: `ad6c87ad4bbe83d528cba54048680aa9861a9df0171db08c393ff7ce03cd0049`.

## English

AccesShot 3.0 adds a Spanish and English interface for organizing programs, modern Windows apps and web pages on a customizable canvas.

- Use the vertical **LANGUAGE** button between **MODES** and **OPTIONS** to switch between English and Spanish. The flag shows the active language.
- The first launch opens in Spanish. The per-user choice is saved in `%APPDATA%\AccessShot\language.json`.
- Custom shortcut names and targets stay unchanged when you switch languages.
- Includes a self-contained portable package for Windows 11 x64. Extract the ZIP and open `AccessShot.exe`.

ZIP SHA-256: `ad6c87ad4bbe83d528cba54048680aa9861a9df0171db08c393ff7ce03cd0049`.
